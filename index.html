🤖 Robot Laberinto Autonomo

Mario Yanez

Auto robotico autonomo desarrollado con logica difusa y matrices de profundidad para navegacion de laberintos.

Tecnologias: C++, Arduino, Logica Difusa

El robot utiliza sensores ultrasonicos para medir distancias en tiempo real y toma decisiones de giro utilizando un sistema de logica difusa implementado en C++.

El proyecto fue desarrollado durante el segundo semestre y presentado en la feria de proyectos de la facultad.

📊 Dashboard de Estadisticas

Lucas Campos

Panel de control que muestra estadisticas de ventas en tiempo real con graficos interactivos.

El dashboard consume una API REST para obtener datos actualizados cada 30 segundos. Utiliza Chart.js para renderizar los graficos y permite filtrar por fecha y categoria.

Fue desarrollado como proyecto final del ramo de Bases de Datos.

Tecnologias: JavaScript, Chart.js, REST API, CSS Grid
