Laboratorio 3 Interactividad con JavaScript sobre el sitio del grupo Asignatura Programación de Aplicaciones Unidad Unidad II – Frontend Actividad Laboratorio 3 – Interactividad con JavaScript (eventos y DOM) Duración total del bloque 80 minutos (60 minutos de actividad principal + 20 minutos de holgura) Modalidad de trabajo Grupal. Mismos grupos del Laboratorio 1 y 2. Herramientas necesarias Computador con acceso a internet, el repositorio de GitHub del grupo, un editor de código, el navegador con herramientas de desarrollador (F12, consola), y una herramienta de inteligencia artificial para apoyar la escritura de JavaScript. 1. Cómo leer esta guía Este documento explica, paso a paso, lo que el grupo debe hacer durante el laboratorio. Cada paso indica exactamente qué acción realizar y cuánto tiempo debería tomar. Los tiempos indicados son una referencia para organizar el trabajo del grupo, no un límite estricto para cada paso individual. Al final del documento se detalla exactamente qué deben entregar y cómo se evaluará el trabajo. 2. Objetivo del laboratorio Al finalizar este laboratorio, el sitio web del grupo va a reaccionar a las acciones del usuario: va a tener al menos una función interactiva compartida por todo el equipo, y cada integrante va a haber agregado su propia interacción usando JavaScript y el DOM. Este laboratorio tiene dos objetivos, y los dos son igual de importantes: Que el sitio tenga al menos una función interactiva construida en equipo y compartida por todo el sitio, por ejemplo un botón que active o desactive un modo oscuro. Que cada integrante agregue una interacción propia en su sección, seleccionando un elemento del DOM y reaccionando a un evento del usuario. 3. Antes de empezar Trabajen en los mismos grupos del Laboratorio 1 y 2. No es necesario volver a formar grupos. La persona anfitriona hace pull de la rama main para asegurarse de que todos trabajan sobre la versión más actualizada del repositorio, ya con los estilos del Laboratorio 2 integrados. Abran el sitio en el navegador y tengan la consola (F12) visible durante todo el laboratorio, para detectar errores de JavaScript apenas aparezcan. 4. ¿Qué significa "trabajar de forma incremental"? Igual que en los laboratorios anteriores, van a usar una herramienta de inteligencia artificial para apoyar la escritura de JavaScript. Está permitido y es esperable que lo hagan. La misma condición aplica: no le pidan a la IA que genere toda la interactividad del sitio de una sola vez y la suban con un único commit. En cambio, trabajen y suban su código en varios commits pequeños, cada uno con un cambio específico y un mensaje que lo describa. Ejemplo concreto de cinco commits incrementales para una sola persona: Commit 1: "Agrego script.js vacío y lo enlazo en mi index.html con defer". Commit 2: "Selecciono el elemento de mi sección con querySelector". Commit 3: "Agrego un event listener al elemento seleccionado". Commit 4: "La función modifica el DOM al hacer clic" (cambia texto, clase o estilo). Commit 5: "Corrijo detalles y confirmo que no hay errores en la consola". Cada grupo debe repetir este patrón de al menos 5 commits por cada integrante. Los commits con menos de 5 por integrante, o que suban todo el trabajo de golpe en uno o dos commits, no cumplen con este requisito. 5. Pasos del laboratorio Paso 1 — Crear el archivo JavaScript compartido (10 minutos) La persona anfitriona crea una rama nueva para este paso, por ejemplo interactividad-base. Crea un archivo script.js en la raíz del proyecto y lo enlaza en el index.html con &lt;script src="script.js" defer&gt;&lt;/script&gt;, justo antes de cerrar el body. Hace commit de este cambio, abre un Pull Request hacia main y el grupo lo revisa y aprueba de inmediato, antes de seguir con el paso 2. Paso 2 — Función interactiva de equipo (10 minutos) Sobre la rama ya integrada a main, el grupo decide en conjunto una función interactiva simple que aplique a todo el sitio, por ejemplo un botón que active o desactive un modo oscuro usando classList.toggle sobre el body. La persona anfitriona (o quien el grupo decida) implementa esta función, hace commit y la integra a main mediante un Pull Request, antes de que cada integrante siga con su propia sección. Paso 3 — Cada integrante agrega su propia interacción (20 minutos) Todo el grupo hace pull de main para tener la función interactiva de equipo ya integrada. Cada integrante crea su propia rama a partir de main, por ejemplo interactividad-nombre. Cada integrante selecciona al menos un elemento de su sección con querySelector, y usa addEventListener para reaccionar a un evento (click, mouseover u otro) modificando el DOM como resultado: mostrar u ocultar texto, cambiar una clase, o actualizar un valor en pantalla. Cada integrante sube su trabajo en al menos 5 commits incrementales, como se explicó en la sección 4 de este documento, y hace push de su rama al repositorio. Paso 4 — Probar en el navegador y revisar la consola (10 minutos) Cada integrante prueba su interacción directamente en el navegador, haciendo la acción que dispara el evento (por ejemplo, hacer clic en el botón correspondiente). Revisan la consola (F12) y confirman que no aparece ningún error antes de continuar. Si hay un error, lo corrigen antes de abrir el Pull Request. Paso 5 — Pull Request, merge y cierre (12 minutos) Cada integrante abre un Pull Request desde su propia rama hacia main. La persona anfitriona revisa cada Pull Request y realiza el merge hacia main, uno por uno, probando en el navegador que cada interacción sigue funcionando después de integrarse. Paso 6 — Registro de evidencia (8 minutos) El grupo prueba el sitio completo en la rama main ya integrada: la función interactiva de equipo y la interacción individual de cada integrante. El grupo crea un documento Word nuevo, distinto a este documento, llamado Evidencia_Laboratorio3_NombreDelGrupo, y pega una captura de pantalla del sitio funcionando, de la consola sin errores, y de al menos un Pull Request con sus commits. 6. Qué deben entregar y dónde Antes de que termine el bloque, cada grupo debe subir a Aula Digital, en la tarea correspondiente a este laboratorio, los dos elementos siguientes: Un enlace (link) al repositorio de GitHub del grupo, ya actualizado con los cambios de este laboratorio. El documento Word con la evidencia de cada paso, descrito en el Paso 6 de este documento. Solo es necesario que un integrante del grupo realice la entrega en Aula Digital, indicando en la entrega el nombre de todos los integrantes del grupo. 7. Pauta de evaluación El docente evaluará el trabajo de cada grupo usando la siguiente pauta. Cada criterio se marca como Logrado o No logrado. No existen puntajes intermedios. N° Criterio a evaluar Logrado No logrado 1 El grupo implementó una función interactiva compartida (por ejemplo, un modo oscuro) e integrada a main antes de que los integrantes agregaran su propia interacción. ☐ ☐ 2 El grupo creó un archivo JavaScript externo, correctamente enlazado al HTML con el atributo defer. ☐ ☐ 3 Cada integrante seleccionó al menos un elemento de su sección con querySelector o querySelectorAll. ☐ ☐ 4 Cada integrante usó addEventListener para reaccionar a un evento y modificar el DOM como resultado. ☐ ☐ 5 Cada integrante realizó como mínimo 5 commits incrementales de JavaScript en su propia rama. ☐ ☐ 6 Cada integrante abrió un Pull Request hacia main, se realizó el merge, y el sitio final funciona sin errores en la consola del navegador. ☐ ☐ 7 El grupo entregó, dentro del plazo, el enlace al repositorio actualizado y el documento Word con evidencia de cada paso. ☐ ☐ Cómo se calcula la nota Todos los criterios tienen el mismo valor. La nota se calcula contando cuántos criterios quedaron marcados como "Logrado" (un número entre 0 y 7), y luego aplicando la siguiente fórmula: Nota = 1,0 + (N° de criterios Logrado ÷ 7) × 6,0 Para no tener que calcular la fórmula cada vez, aquí está el resultado ya calculado para cada cantidad posible de criterios logrados: N° de criterios "Logrado" (de 7) Nota (escala 1,0 a 7,0) 0 1,0 1 1,9 2 2,7 3 3,6 4 4,4 5 5,3 6 6,1 7 7,0 Ejemplo: si un grupo obtuvo 5 de los 7 criterios como "Logrado", la nota de ese grupo es 5,3.
