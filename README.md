# Portafolio de Proyectos del Grupo

Este sitio web reúne y presenta los proyectos de todos los integrantes de nuestro equipo. Fue construido de forma colaborativa utilizando Git y GitHub como parte del Laboratorio 1 de Programación de Aplicaciones.
